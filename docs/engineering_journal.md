## Sprint 2 - Scanner Manager Design

### Purpose

The Scanner Manager acts as the central controller for all security scanners.

### Responsibilities

- Receive scan requests
- Select the appropriate scanner
- Execute the scan
- Collect results
- Return structured output

### Benefits

- Easy to add new scanners
- Modular architecture
- Cleaner code
- Easier maintenance
